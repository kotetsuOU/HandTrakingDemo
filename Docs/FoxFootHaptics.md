# Fox Foot Haptics (キツネの四足追従ハプティクス) 仕様書

本モジュールは、キツネ（Fox）などの4足歩行キャラクターのボーン（Bone）アニメーションに合わせて、その4つの足先に焦点を合わせた空中超音波フィードバックを照射するシステムです。

---

## 1. 概要
`HAP_FoxFootHapticsController.cs` は、キャラクターの骨格階層内から指定したパターン名（例: `Fox_F_LLegDigit11` 等）に合致する足先のボーン（Transform）を再帰的検索によって自動検出・バインドします。

`HAP_AUTDController` のハプティクス送信ループ（`UpdateHaptics`）と連携し、キャラクターが移動・アニメーションするのに追従して、リアルタイムに足の位置へ超音波の焦点を形成します。

---

## 2. 照射モードの分類 (STM Mode)
`HAP_AUTDController` のホログラフィアルゴリズム (`HoloAlgorithm`) を **`Custom`** に設定した場合、インスペクタの `STM Mode` の設定に応じて、ハードウェアまたはPC側で計算された高速な時分割（STM）照射が行えます。

### ① FociSTM (ハードウェア計算・単焦点)
* **概要**: ハードウェア(FPGA)側で単焦点を計算・巡回させる超高速かつ超軽量なモードです。
* **動作**: 接地している足に対して、指定した周波数（STM Frequency）で1本ずつ高速に焦点を切り替えます。
* **特徴**:
  * 演算負荷が極めて低く、非常に高い周波数（150Hz等）での切り替えが可能です。
  * このモードでは自動的に `Track Mode = Sequential` (単焦点巡回) かつ `Algorithm = Naive` 扱いになります。

### ② GainSTM (PC計算・複数焦点対応)
* **概要**: PC側で全フレームの焦点や位相を事前計算し、バッファとしてデバイスに送信するモードです。
* **動作**: `Track Mode` や `Custom Inner Algorithm` の組み合わせにより、柔軟な照射が可能です。
  * **Track Mode = Sequential**: 接地している足を1本ずつ巡回します。GSPATを使用すると、より正確で高品質な単焦点STMを形成できます。
  * **Track Mode = Simultaneous**: 接地しているすべての足に対して**同時**に焦点を形成します。STMを使用せず、毎フレームPCでGSPATを解き直す動作になります。
* **特徴**:
  * 複数焦点の最適化（GSPAT等）をハードウェアSTMとして利用できますが、PC側の演算負荷が高くなります。

## 3. インスペクター設定パラメータ (HAP_FoxFootHapticsController)

### 基本設定
* **`Front Left / Front Right / Back Left / Back Right Foot`**: バインドされた足ボーンのTransform（未指定の場合は起動時に自動検出されます）。
* **`Enable Front Left / Front Right / Back Left / Back Right`**: それぞれの足への照射を個別で有効化/無効化するトグル。

### 接地判定設定
* **`Only Target Grounded`**: 有効にすると、地面に接触しているとみなされる高さにある足のみを照射対象にします。
* **`Height Threshold`**: 接地と判定するための、ルート位置からの高さのしきい値（メートル）。このしきい値を超えると「滞空（空中）」と判定され、照射がスキップされます。
* **`Root Transform`**: 接地の基準となるキャラクターのルートTransform（通常はキャラクターの Root オブジェクト）。未指定時はコンポーネントがアタッチされたオブジェクトを使用します。
* **`Foot Target Normal`**: 方向グルーピング（`enableDirectionalGrouping`）用のクラスタ法線。どの向きのデバイスから照射するかを決定するヒントとして機能します。
  * 上から下に向けて照射するデバイス群を想定する場合: `(0, -1, 0)` （`Vector3.down`）
  * 下から上に向けて照射するデバイス群を想定する場合: `(0, 1, 0)` （`Vector3.up`）

### カスタムモード設定 (Custom Mode Settings)
* **`STM Mode`**: 使用するSTMの種類（`FociSTM` または `GainSTM`）を選択します。
* **`STM Frequency (Hz)`**: 高速シーケンシャル照射時の切り替え周波数。
* **`Track Mode`**: ターゲットの追跡・照射方式（`Sequential` または `Simultaneous`）。※`GainSTM` 選択時のみ表示
* **`Custom Inner Algorithm`**: 使用する内部ソルバー（`Naive` または `GSPAT`）。※`GainSTM` 選択時のみ表示

## 4. デバッグと視覚化 (Gizmos)
Sceneビュー上でのリアルタイムな動作確認のため、以下のGizmoが描画されます。

* **足先の球体（Wireframe Sphere & Solid Sphere）**:
  * 有効かつターゲットとなっている（照射中）足：**緑色のワイヤー球および実線球**で強調描画されます。（STMモード時は接地しているすべての足がアクティブとして描画されます）。
  * 非アクティブまたは滞空中のため除外されている足：**赤色のワイヤー球**で描画されます。
* **`Debug Force Active All Feet`**: 
  * デバッグ用強制モード。有効化すると個別トグルや接地判定（高さ判定）を完全に無視し、**4つの足すべてを常時有効・接地状態**として扱います。
* **接地しきい値と接続線（Grounded Visualizer）**:
  * `heightThreshold` のレベルを示す小さな十字マークが表示されます。
  * 足先から地面に向けて引かれる接続線：
    * **接地内（有効接触）**：緑色の接続線を描画。
    * **接地外（空中滞空）**：しきい値より上の部分を赤線、下の部分を緑線で描き分け、しきい値をどの程度超過しているかが一目で分かります。
