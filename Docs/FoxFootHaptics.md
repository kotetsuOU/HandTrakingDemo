# Fox Foot Haptics (キツネの足足追従ハプティクス) 仕様書

本モジュールは、キツネ（Fox）などの4足歩行キャラクターのボーン（Bone）アニメーションに合わせて、その4つの足先に焦点を合わせた空中超音波フィードバックを照射するシステムです。

---

## 1. 概要
`HAP_FoxFootHapticsController.cs` は、キャラクターの骨格階層内から指定したパターン名（例: `Fox_F_LLegDigit11` 等）に合致する足先のボーン（Transform）を再帰的検索によって自動検出・バインドします。

`HAP_AUTDController` のハプティクス送信タスク（`_hapticsSendTask`）と連携し、キャラクターが移動・アニメーションするのに追従して、リアルタイムに足の位置へ超音波の焦点を形成します。

---

## 2. 照射モードの分類
`HAP_AUTDController` のホログラフィアルゴリズム (`HoloAlgorithm`) を **`Custom`** に設定した場合、本コントローラーの `customInnerAlgorithm`（内部ソルバー）の設定に応じて、以下の2つの照射動作が選択できます。

### ① 疑似STMモード（単焦点・時計回り巡回）
* **設定**: `customInnerAlgorithm = HoloSolverAlgorithm.Naive`
* **動作**: 有効かつ設置している足候補の中から、**毎フレーム（または指定フレーム数）ごとに時計回り（前左 → 前右 → 後右 → 後左）に1つの足先だけを順番に選択し、単一焦点を照射**します。
* **特徴**:
  * 単一の焦点のみを形成するため、干渉最適化による演算負荷がない `Naive` ソルバーを使用し、非常に軽量（計算量 $O(N)$）で動作します。
  * 浮いている（非接地の）足は自動的にスキップされ、**接地している足の間だけで巡回**します（例: 前の2本足のみが接地している場合、その2本を交互に往復する「2フレーム1周期」の照射になります）。
  * 巡回周期は `framesPerFoot` パラメータで制御できます（長めにすることで皮膚への刺激エネルギー時間を十分に稼ぎ、出力を強く感じさせることができます）。

### ② 同時マルチフォーカスモード
* **設定**: `customInnerAlgorithm = HoloSolverAlgorithm.GSPAT`
* **動作**: **現在有効かつ接地しているすべての足先に対して、同時に複数の焦点を形成**します。
* **特徴**:
  * 多焦点の最適化位相を求めるため、内部で `GSPAT` 演算エンジンを走らせます。
  * 接地しているすべての足に対して同時にフィードバックを提示したい場合に選択します。

## 3. インスペクター設定パラメータ (HAP_FoxFootHapticsController)

### 基本設定
* **`Front Left / Front Right / Back Left / Back Right Foot`**: バインドされた足ボーンのTransform（未指定の場合は起動時に自動検出されます）。
* **`Enable Front Left / Front Right / Back Left / Back Right`**: それぞれの足への照射を個別で有効化/無効化するトグル。

### 接地判定設定
* **`Only Target Grounded`**: 有効にすると、地面に接触しているとみなされる高さにある足のみを照射対象にします。
* **`Height Threshold`**: 接地と判定するための、ルートトランスフォームからの最大高さ（メートル）。このしきい値を超えると「滞空（空中）」と判定され、照射がスキップされます。
* **`Root Transform`**: 接地の基準となるキャラクターの足元ルート座標（通常はキャラクターの Root オブジェクト）。未指定時はコンポーネントがアタッチされたオブジェクトを使用します。
* **`Foot Target Normal`**: 方向グルーピング（`enableDirectionalGrouping`）用のクラスタ法線。どの向きのデバイスから照射するかを決定するヒントとして機能します。
  * 上から下に向けて照射するデバイス群を想定する場合: `(0, -1, 0)` （`Vector3.down`）
  * 下から上に向けて照射するデバイス群を想定する場合: `(0, 1, 0)` （`Vector3.up`）

### カスタムモード設定 (Custom Mode Settings)
* **`Frames Per Foot`**: 疑似STM巡回時、同じ足を何フレーム間照射し続けるか（デフォルト: `5`）。値を大きくすると照射時間が長くなり、触覚の強さを高めることができます。
* **`Debug Force Active All Feet`**: デバッグ用強制モード。有効化すると個別トグルや接地判定（高さ判定）を完全に無視し、**4つの足すべてを常時有効・接地状態**として扱います。
* **`Custom Inner Algorithm`**: `HoloAlgorithm.Custom` 選択時に、内部的に使用する計算エンジン（`Naive` または `GSPAT`）を選択します。

## 4. デバッグと視覚化 (Gizmos)
Sceneビュー上でのリアルタイムな動作確認のため、以下のGizmoが描画されます。

* **足先の球体（Wireframe Sphere）**:
  * 有効かつターゲットとなっている（照射中）足：**緑色のワイヤー球**で描画されます。
  * 非アクティブまたは滞空中のため除外されている足：**赤色のワイヤー球**で描画されます。
* **疑似STMの追従コア（Solid Sphere）**:
  * 疑似STMモード（`Custom + Naive`）のプレイ中、現在超音波が照射されている1つの足の内部に、**塗りつぶされた緑色のコア球**が描画され、時計回りに高速回転する様子が視覚的に確認できます。
* **接地しきい値と接続線（Grounded Visualizer）**:
  * `heightThreshold` のレベルを示す小さな十字マークが表示されます。
  * 足先から地面に向けて引かれる接続線：
    * **接地内（有効接触）**：緑色の接続線を描画。
    * **接地外（空中滞空）**：しきい値より上の部分を赤線、下の部分を緑線で描き分け、しきい値をどの程度超過しているかが一目で分かります。
